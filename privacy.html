Политика конфиденциальности

Дата вступления в силу: 18 ноября 2026 года

Настоящая Политика конфиденциальности описывает, какие данные могут обрабатываться при использовании настольного приложения StreamHunter AI и сайта StreamHunter AI. Используя приложение или сайт, пользователь подтверждает, что ознакомился с настоящей Политикой.

1. Какие данные обрабатываются

В зависимости от используемых функций приложение может обрабатывать:

  • локальные видеофайлы, ссылки на трансляции и клипы;
  • названия клипов, сведения о стримерах и другую информацию, связанную с видео;
  • текстовые расшифровки речи из видео;
  • созданные пользователем названия, описания, хештеги и другие материалы публикаций;
  • сведения о подключённых аккаунтах и статусах интеграций;
  • технические данные, необходимые для работы приложения и его интеграций.

2. Локальное хранение данных

StreamHunter AI является настольным приложением. Часть рабочих данных, включая сведения о клипах, настройках, черновиках и очереди публикаций, хранится локально на устройстве пользователя в базе данных SQLite.

OAuth-токены подключённых социальных аккаунтов, управляемых через модуль социальных аккаунтов, сохраняются с использованием системного хранилища учётных данных Windows. Данные авторизации Twitch в текущей реализации приложения сохраняются в локальном файле в пользовательском профиле операционной системы.

Пользователь самостоятельно отвечает за безопасность своего устройства, учётной записи Windows, резервных копий и файлов приложения.

3. Использование сторонних сервисов

Для работы отдельных функций StreamHunter AI взаимодействует со сторонними сервисами. Эти сервисы обрабатывают данные в соответствии со своими политиками конфиденциальности и условиями использования.

  • Twitch. При подключении Twitch приложение использует Twitch API и OAuth для получения разрешённых пользователем данных, например информации об аккаунте и каналах, на которые он подписан. Сервис Twitch: Политика конфиденциальности Twitch.
  • Google и YouTube. При подключении YouTube пользователь проходит авторизацию Google OAuth. В зависимости от выданных разрешений приложение может получать сведения о YouTube-канале и использовать возможности YouTube API. Сервисы Google: Политика конфиденциальности Google.
  • Google Gemini. При использовании AI-генерации приложение отправляет текстовую расшифровку клипа в Gemini API для подготовки вариантов названий и материалов публикации. В текущей реализации в запрос передаётся текст расшифровки, а не сам видеофайл. Подробнее: Условия Gemini API.
  • GitHub Pages. Этот сайт размещается с помощью GitHub Pages. При посещении сайта GitHub может обрабатывать технические данные, необходимые для предоставления и защиты сервиса: Политика конфиденциальности GitHub.

4. Цели обработки

Данные используются для следующих целей:

  • предоставление функций анализа видео и работы с клипами;
  • подключение аккаунтов и выполнение запросов к API выбранных сервисов;
  • генерация текстовых материалов с помощью AI;
  • хранение настроек, черновиков и состояния задач;
  • обеспечение стабильной работы и устранение технических ошибок.

5. Передача данных

StreamHunter AI не предоставляет разработчику автоматический доступ к локальным файлам пользователя. Однако данные могут передаваться соответствующим сторонним сервисам, когда пользователь запускает функции, требующие такого взаимодействия. Например, текст расшифровки передаётся Gemini API при запросе AI-генерации.

Разработчик не продаёт персональные данные пользователей. Передача данных может происходить в случаях, необходимых для работы выбранных интеграций, соблюдения закона или защиты прав и безопасности.

6. Хранение и удаление данных

Локальные данные могут храниться до тех пор, пока пользователь не удалит их самостоятельно или не удалит соответствующие файлы приложения. Подключённые аккаунты можно отключить средствами приложения, если такая функция доступна в используемой версии. Пользователь также может отозвать ранее выданные разрешения в настройках соответствующего стороннего сервиса.

Удаление приложения само по себе может не удалить все пользовательские данные, сохранённые в профиле Windows, системном хранилище учётных данных или других каталогах.

7. Безопасность

Для защиты данных используются локальное хранение, системное хранилище учётных данных Windows для поддерживаемых интеграций и механизмы авторизации сторонних платформ. Ни один способ хранения или передачи данных не может гарантировать абсолютную безопасность.

Пользователь не должен передавать третьим лицам OAuth-токены, API-ключи, файлы конфигурации с секретами и другие данные авторизации.

8. Конфиденциальность несовершеннолетних

Приложение не предназначено для самостоятельного использования детьми без согласия и контроля законного представителя. Мы сознательно не запрашиваем через этот сайт специальные категории персональных данных.

9. Изменения Политики

Политика может обновляться при изменении функций приложения, интеграций или применимых требований. Актуальная версия публикуется на этой странице.
